# SalesOps Mobile Prototype

Борлуулалтын компанийн дотоод хэрэглээнд зориулсан mobile-first prototype.

## Одоогийн боломжууд

- Ажилтан, борлуулагч, нягтлан гэсэн эрхээр нэвтрэх demo flow
- Batmon logo болон blue theme
- Ажлын байр дээр байршил баталгаажуулж цаг эхлүүлэх / тарахдаа дуусгах
- Ажилласан цагийг өдөр, сар, жилээр харах
- Борлуулагч захиалга оруулах
- Дансаар болон бэлнээр авсан мөнгө бүртгэх
- Борлуулалтын төлөвлөгөө, гүйцэтгэлийн хувь, өдөр/сар борлуулалтын graphic dashboard
- Нягтлан бүх захиалга, төлбөрийн дүнг харах
- Demo өгөгдөл болон localStorage хадгалалт

## Нээж турших

`index.html` файлыг browser дээр нээхэд ажиллана.

Demo нэвтрэлт:

- Нэр: дурын
- Нууц үг: `1234`
- Эрх: Борлуулагч / Ажилтан / Нягтлан

## Дараагийн production алхмууд

- React Native эсвэл Flutter mobile app болгох
- Backend API, database, user permission нэмэх
- GPS/location баталгаажуулалттай цаг бүртгэл
- Захиалгын барааны master data
- Нягтлангийн export: Excel/PDF
- Bank statement тулгалт болон cash handover баталгаажуулалт
